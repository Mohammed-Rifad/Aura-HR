# AURA HR
## Executive Summary

**Version:** 1.0.0

**Project Type:** Enterprise SaaS Application

**Category:** Human Resource Management System (HRMS) with Agentic AI

**Technology Stack:**
- Frontend: Next.js + TypeScript + Tailwind CSS
- Backend: Django + Django REST Framework
- Database: PostgreSQL
- Cache: Redis
- Background Jobs: Celery
- AI: LangGraph + LangChain + OpenAI/Ollama
- Deployment: Docker + AWS + Nginx

---

# Overview

AURA HR is a modern AI-powered Human Resource Management Platform designed for medium and large organizations.

Unlike traditional HR software, AURA HR combines enterprise HR management with Agentic AI, allowing intelligent software agents to assist HR professionals, managers, recruiters, and employees in completing everyday tasks.

The platform focuses on improving productivity, reducing repetitive manual work, automating workflows, and enabling natural language interactions with HR systems.

---

# Vision

# Problem Statement

Traditional HR systems require users to manually navigate multiple screens for common tasks.

Examples include:

- Applying leave
- Generating offer letters
- Updating employee profiles
- Searching HR policies
- Screening resumes
- Tracking document expiry
- Generating reports

These repetitive tasks consume valuable time and increase operational costs.

---

# Proposed Solution

AURA HR introduces an Agentic AI layer that assists users through natural language conversations.

Instead of manually completing forms, users can communicate with intelligent AI agents capable of:

- Understanding requests
- Planning tasks
- Calling business services
- Generating documents
- Retrieving company knowledge
- Producing business insights

Sensitive operations always require human approval before execution.
